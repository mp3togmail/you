# Kosher YouTube Downloader

A secure, community-approved YouTube downloader service with AI-powered content moderation.

## Features
- Email-triggered video downloads
- AI-powered content moderation (adult content, inappropriate imagery detection)
- Automatic background blur for background content violations
- Audio extraction with adult content filtering
- MP3/MP4 format support
- Google Drive integration
- Admin approval workflow
- HTML-formatted email responses with download links

## Project Structure
- `.github/workflows/` - GitHub Actions workflows
- `scripts/` - Processing scripts (content validation, video processing)
- `config/` - Configuration files
- `templates/` - Email templates
- `docs/` - Documentation
